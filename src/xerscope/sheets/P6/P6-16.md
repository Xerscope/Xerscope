# P6-16 · Dangling Start Activities

Activities whose start is not driven by any predecessor.

## Population (denominator)
Start: every activity of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never an activity).

No step: the P6 Professional report divides by every activity (R1). Started activities and milestones stay in the denominator; they are never counted.

## Counted (numerator)
Not started (`TASK.status_code` = `TK_NotStart`), not a milestone, with at least one
predecessor, none of them FS (`PR_FS`) or SS (`PR_SS`): only FF or SF links into it.
An activity with no predecessor at all is P6-01's, not this one's.

Value = counted / population × 100. Target `<= 0%`, set in `p6.toml`: Oracle documents no default.

## Source
- [P6 Professional help, Relationships and Assignments tab (113174)](https://docs.oracle.com/cd/G48902_01/client_help/en_US/113174.htm):
  start not driven by predecessors, including activities with only FF or SF predecessors;
  option "Ignore in-progress activities". xerscope reads the option as checked, as in R1.
- Population and milestone exclusion: P6 Professional report R1 (`docs/standards.md`).

## Example
| Activity | Status | Predecessors | Result |
|---|---|---|---|
| A110 | Not started | A100 (FF) | counted |
| A120 | Not started | A100 (FS), A110 (FF) | checked, not counted |
| A130 | In progress | A100 (FF) | checked, not counted (in progress) |
| A140 | Not started | none | checked, not counted (P6-01) |

1 counted / 5 activities (with A100) = 20.0 %.

## Change it
Target only: `target` of `P6-16` in `standards/p6.toml`. The constraint options of the dialog
are not read (`UNRESOLVED`).
