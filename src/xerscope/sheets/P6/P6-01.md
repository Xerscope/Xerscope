# P6-01 · Logic

Open activities with no predecessor or no successor.

## Population (denominator)
Start: every activity of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never an activity).
1. not complete: `TASK.status_code` is not `TK_Complete` (101248)

Level of effort stays in: the help does not exclude it.

## Counted (numerator)
An activity with no predecessor, or no successor, among the project's relationships
(`TASKPRED.task_id` = successor, `TASKPRED.pred_task_id` = predecessor).
- A link to an activity of another project (`TASKPRED.pred_proj_id` differs) counts as logic.
- Predecessor not required: started activities (`status_code` is not `TK_NotStart`) and
  start milestones (`task_type` = `TT_Mile`).
- A finish milestone (`TT_FinMile`) without successor is counted.
- Column `reason`: no predecessor / no successor / no predecessor, no successor.

Value = counted / population × 100. Target `< 5%`.

## Source
- [P6 Professional help, Check Schedule dialog box (101248)](https://docs.oracle.com/cd/G18296_01/client_help/en_US/101248.htm):
  started activities and start milestones need no predecessor; completed and WBS summary
  activities are not included.
- [P6 EPPM help, Relationships section (46291)](https://docs.oracle.com/cd/G18294_01/p6help/en/46291.htm):
  external predecessors or successors pass. It also lets finish milestones pass the successor
  check; P6 Professional does not say so.
- [Ten Six, P6 Professional r22.12 report](https://tensix.com/using-the-p6-check-schedule-tool/):
  the Project Complete milestone without successor is flagged. xerscope follows this report.

## Example
| Activity | Status | Type | Pred. | Succ. | Result |
|---|---|---|---|---|---|
| A100 | Complete | Task | – | A110 | out of population |
| A110 | In progress | Task | – | A120 | checked, not counted (started) |
| A120 | Not started | Task | A110 | – | counted: no successor |
| M900 | Not started | Finish milestone | A120 | – | counted: no successor |

1 + 1 = 2 counted / 3 checked = 66.7 %.

## Change it
Target only: `target` of `P6-01` in `standards/p6.toml`. For the EPPM reading (finish
milestones pass), use the rule `missing_logic` in your own standard with
`succ_exempt = ["finish_milestone"]`.
