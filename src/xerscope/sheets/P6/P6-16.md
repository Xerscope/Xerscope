# P6-16 · Dangling Start Activities

Tasks whose start is not driven by any predecessor.

## Population (denominator)
Start: every task of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never a task).

No step: the P6 Professional report divides by every task (R1). Milestones, completed tasks and, with
`ignore_in_progress = true`, in-progress tasks stay in the denominator; they are never counted.

## Counted (numerator)
Not started (`TASK.status_code` = `TK_NotStart`), or in progress (`TK_Active`) when
`ignore_in_progress = false`; not a milestone; with at least one predecessor, none of them FS
(`PR_FS`) or SS (`PR_SS`): only FF or SF links into it.
A task with no predecessor at all is P6-01's, not this one's.

Value = counted / population × 100. Target `<= 0%`, set in `p6.toml`: Oracle documents no default.

## Source
- [P6 Professional help, Relationships and Assignments tab (113174)](https://docs.oracle.com/cd/G48902_01/client_help/en_US/113174.htm):
  start not driven by predecessors, including tasks with only FF or SF predecessors;
  option "Ignore in-progress activities for dangling start activities: Mark to disregard activities
  that are in progress when checking for activities with start dates not driven by their
  predecessors." Oracle documents no default; `p6.toml` sets it checked, as in R1. Read as: the task
  leaves the numerator, not the denominator.
- Population and milestone exclusion: P6 Professional report R1 (`docs/standards.md`).

## Example
| Task | Status | Predecessors | Result |
|---|---|---|---|
| A110 | Not started | A100 (FF) | counted |
| A120 | Not started | A100 (FS), A110 (FF) | checked, not counted |
| A130 | In progress | A100 (FF) | checked, not counted (in progress) |
| A140 | Not started | none | checked, not counted (P6-01) |

1 counted / 5 tasks (with A100) = 20.0 %.

## Change it
`target` and `params = { ignore_in_progress = true }` of `P6-16` in `standards/p6.toml`: set the
option as it is in your P6 dialog.
