# P6-06 · Large float

Open activities with total float above x.

## Population (denominator)
Start: every activity of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never an activity).
1. not complete: `TASK.status_code` is not `TK_Complete` (101248)
2. not level of effort: `TASK.task_type` is not `TT_LOE` (101248)

Milestones stay in.

## Counted (numerator)
`TASK.total_float_hr_cnt` > `limit_hours`, the float P6 stored at the last schedule (F9),
in hours. x = `limit_hours = 352` in `p6.toml`.

Value = counted / population × 100. Target `< 1%`.

## Source
- [P6 Professional help (101248)](https://docs.oracle.com/cd/G18296_01/client_help/en_US/101248.htm):
  completed, WBS summary and level of effort activities are not included; the limit is the value set.
- [P6 EPPM help, Large Float section (46284)](https://docs.oracle.com/cd/G18294_01/p6help/en/46284.htm):
  WBS summary, actual-finish and level of effort activities removed; the limit is in hours.
- [P6 EPPM help, dialog defaults (91574)](https://docs.oracle.com/cd/G18294_01/p6help/en/91574.htm):
  352 h, target less than 1 %.

## Example
| Activity | Calendar | `total_float_hr_cnt` | Result |
|---|---|---|---|
| A100 | 10 h/day | 400 | counted (40 d, 400 h > 352 h) |
| A110 | 8 h/day | 353 | counted |
| A120 | 8 h/day | 352 | checked, not counted |

2 counted / 3 checked = 66.7 %. DCMA-06 (44 working days) counts only A110.

## Change it
x: `params = { limit_hours = 352 }` of `P6-06` in `standards/p6.toml`. Target: `target`.
