# P6-17 · Dangling Finish Activities

Tasks whose finish drives no successor.

## Population (denominator)
Start: every task of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never a task).

No step: the P6 Professional report divides by every task (R1). Complete tasks and milestones stay in the denominator; they are never counted.

## Counted (numerator)
Not complete (`TASK.status_code` is not `TK_Complete`), not a milestone, with at least one
successor, none of them FS (`PR_FS`) or FF (`PR_FF`): only SS or SF links out of it.
A task with no successor at all is P6-01's.

Value = counted / population × 100. Target `<= 0%`, set in `p6.toml`: Oracle documents no default.

## Source
- [P6 Professional help, Relationships and Assignments tab (113174)](https://docs.oracle.com/cd/G48902_01/client_help/en_US/113174.htm):
  finish dates that do not drive successors; options to ignore tasks with soft or hard
  constraints, not read by xerscope.
- Population and milestone exclusion: P6 Professional report R1 (`docs/standards.md`).

## Example
| Task | Status | Successors | Result |
|---|---|---|---|
| A100 | Not started | A110 (SS) | counted |
| A110 | Not started | A120 (FS) | checked, not counted |
| A120 | Not started | none | checked, not counted (P6-01) |

1 counted / 3 tasks = 33.3 %.

Target only: `target` of `P6-17` in `standards/p6.toml`.
