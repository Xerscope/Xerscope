# P6-03 · Soft Constraints

Open tasks with a constraint P6 can still schedule around.

## Population (denominator)
Start: every task of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never a task).
1. not complete: `TASK.status_code` is not `TK_Complete` (101248)
2. not level of effort: `TASK.task_type` is not `TT_LOE` (101248)

Milestones stay in.

## Counted (numerator)
`TASK.cstr_type` or `TASK.cstr_type2` is one of:

| XER code | P6 name |
|---|---|
| `CS_MSOB` | Start On or Before |
| `CS_MSOA` | Start On or After |
| `CS_MEOB` | Finish On or Before |
| `CS_MEOA` | Finish On or After |
| `CS_ALAP` | As Late As Possible |

Same exemption as P6-02: a start constraint on a started task is not counted.

Value = counted / population × 100. Target `< 5%`.

## Source
- [P6 Professional help, Constraints tab (113176)](https://docs.oracle.com/cd/G48902_01/client_help/en_US/113176.htm)
  and [101248](https://docs.oracle.com/cd/G18296_01/client_help/en_US/101248.htm): the five soft
  types above, same exclusions as hard constraints.

## Example
| Task | Status | `cstr_type` | `cstr_type2` | Result |
|---|---|---|---|---|
| A100 | Not started | `CS_MSOA` | – | counted |
| A110 | In progress | `CS_MSOA` | – | checked, not counted (started) |
| A120 | Not started | `CS_MEO` | `CS_MEOB` | counted (secondary is soft) |

2 counted / 3 checked = 66.7 %. A120 is also counted in P6-02.
