# P6-17 · Dangling Finish Activities

Tasks whose finish drives no successor.

## Population (denominator)
Start: every task of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never a task).

No step: the P6 Professional report divides by every task (R1). Complete tasks, milestones and the
constrained tasks the options below leave out stay in the denominator; they are never counted.

## Counted (numerator)
Not complete (`TASK.status_code` is not `TK_Complete`), not a milestone, with at least one
successor, none of them FS (`PR_FS`) or FF (`PR_FF`): only SS or SF links out of it.
A task with no successor at all is P6-01's. With `ignore_soft_constraints = true`, a task whose
primary or secondary constraint (`TASK.cstr_type`, `TASK.cstr_type2`) is Start On (`CS_MSO`), Start On or
After (`CS_MSOA`), Start On or Before (`CS_MSOB`), Finish On (`CS_MEO`), Finish On or After
(`CS_MEOA`), Finish On or Before (`CS_MEOB`) or As Late As Possible (`CS_ALAP`) is not counted; with
`ignore_hard_constraints = true`, one with Mandatory Start (`CS_MANDSTART`) or Mandatory Finish
(`CS_MANDFIN`). These are the sets of the Dangling options, not those of P6-02 / P6-03.

Value = counted / population × 100. Target `<= 0%`, set in `p6.toml`: Oracle documents no default.

## Source
- [P6 Professional help, Relationships and Assignments tab (113174)](https://docs.oracle.com/cd/G48902_01/client_help/en_US/113174.htm):
  finish dates that do not drive successors; options "Ignore activities with soft constraints"
  and "Ignore activities with hard constraints" and their constraint types. Oracle documents no
  default; `p6.toml` leaves both unchecked. Read as: the task leaves the numerator, not the
  denominator.
- Population and milestone exclusion: P6 Professional report R1 (`docs/standards.md`).

## Example
| Task | Status | Successors | Result |
|---|---|---|---|
| A100 | Not started | A110 (SS) | counted |
| A110 | Not started | A120 (FS) | checked, not counted |
| A120 | Not started | none | checked, not counted (P6-01) |

1 counted / 3 tasks = 33.3 %.

## Change it
`target` and `params = { ignore_soft_constraints = false, ignore_hard_constraints = false }` of
`P6-17` in `standards/p6.toml`: set the options as they are in your P6 dialog.
