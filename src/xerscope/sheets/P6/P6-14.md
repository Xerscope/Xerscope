# P6-14 · Negative Float

Open tasks with total float below zero.

## Population (denominator)
Start: every task of the file (`TASK` rows; a WBS summary, `TT_WBS`, is never a task).
1. not complete: `TASK.status_code` is not `TK_Complete` (101248)
2. not level of effort: `TASK.task_type` is not `TT_LOE` (101248)

Milestones stay in.

## Counted (numerator)
`TASK.total_float_hr_cnt` < 0, as stored by the last schedule (F9).

Value = counted / population × 100. Target `< 1%`.

## Source
- [P6 Professional help (101248)](https://docs.oracle.com/cd/G18296_01/client_help/en_US/101248.htm):
  float less than zero; completed, WBS summary and level of effort not included.

## Example
| Task | `total_float_hr_cnt` | Result |
|---|---|---|
| A100 | -8 | counted |
| A110 | 0 | checked, not counted |
| A120 | 120 | checked, not counted |

1 counted / 3 checked = 33.3 %.
