# P6-13 · BEI

Baseline Execution Index: completed tasks against the baseline's tasks.

## Population (denominator)
Start: every task of the baseline (the baseline file's `TASK` rows; with the planned-dates baseline, the update's own).
1. not milestone: `TASK.task_type` is not `TT_Mile` or `TT_FinMile` (101248)
2. not level of effort: `TASK.task_type` is not `TT_LOE` (101248)

No step on the baseline finish: every baseline task counts, whatever its finish (R1). Needs a baseline (sidebar).

## Counted (numerator)
Tasks of the current update that are complete (`TASK.status_code` = `TK_Complete`),
same exclusions. A completed task counts even if it was not due yet, so the counted set
is not a part of the denominator's set.

The list shows the tasks due by the status date in the baseline and not complete.

Value = counted / denominator (ratio). Target `> 0.95`, as report R1 shows it; the
[EPPM dialog help (91574)](https://docs.oracle.com/cd/G18294_01/p6help/en/91574.htm) says 0.95 or
greater, so exactly 0.95 passes in EPPM and fails here.

## Source
- [P6 Professional help (101248)](https://docs.oracle.com/cd/G18296_01/client_help/en_US/101248.htm)
  and [P6 EPPM help, BEI section (46277)](https://docs.oracle.com/cd/G18294_01/p6help/en/46277.htm):
  denominator = baseline tasks finishing before the status date.
- A P6 Professional report (R1, `docs/standards.md`) divides by every baseline task;
  xerscope follows the report. The [Ten Six article](https://tensix.com/using-the-p6-check-schedule-tool/)
  reports a wrong BEI in P6 Professional r22.12 (1.0 where EPPM gives about 0.55).
- Same check in DCMA-14 with the help's reading (due by the status date).

## Example
Baseline: A100–A130, all four task-dependent. Update: A100 and A110 complete, A130 complete
early.

3 counted / 4 baseline tasks = 0.75: fails. With the help's reading, if only
A100–A120 were due: 3 / 3 = 1.00.

## Change it
Target: `target` of `P6-13` in `standards/p6.toml`. The help's reading (due tasks only):
the rule `bei` with `due_from = "baseline"` in your own standard.
